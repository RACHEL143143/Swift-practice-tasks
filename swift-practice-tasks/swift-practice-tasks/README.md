# Swift Practice Tasks

Solutions for the three units in the Swift Programming Practice Tasks PDF.

## Folder structure

- `Unit1_ControlFlow/` — decision-making, loops, and operators (Tasks 1.1–1.18)
- `Unit2_Collections/` — arrays, sets, and dictionaries (Tasks 2.1–2.18)
- `Unit3_EnumStructClass/` — enumerations, structures, and classes (Tasks 3.1–3.17)

## How to run

Open a `.swift` file in Swift Playgrounds or a Swift-compatible environment and run each file separately. Each task is an independent program.

The examples use sample values. Change the values to test other inputs.

## Note

The PDF also contains additional guided, practice, and challenge activities. These files cover the numbered tasks in each unit.
